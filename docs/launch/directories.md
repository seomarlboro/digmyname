## Caveats

- **`glama.json` existing in the repo does nothing by itself** — Glama needs a separate Claim action run outside this repo (row 1), the last one still open. The equivalent step for the official MCP registry (row 5) is done — republished at v1.2.12 with the correct description.
- **PulseMCP is paused platform-wide** right now, not specific to this project — nothing to do there until they reopen (or the registry publish feeds it automatically).
- **Two rows carry a decision, not just busywork**: IndieHackers' paid "Top Products" (~$20, optional) and Peerlist's individual-only profile requirement (can't launch under a "DigMyName" brand account).
- **r/domains is a genuine unknown**, not assumed-safe — verify manually before posting.
- Submission UIs drift; treat every row as a starting point and confirm the live form before submitting.
